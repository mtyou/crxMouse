# Mouse Gesture Lite

一个使用 Chrome Manifest V3 的鼠标右键手势扩展。

点击扩展图标即可为每个功能选择一个手势。保存后会立即同步到已经打开的页面；每个手势只能分配给一个功能。

在链接上按住鼠标右键拖动并松开，可以在新标签页打开该链接。

在 macOS 上，按住右键拖动执行手势，快速点两次右键打开 Chrome 原生菜单。也可以按住 Control 键并单击打开菜单。

## 手势

按住鼠标右键并绘制以下方向，松开鼠标右键执行动作：

| 手势 | 动作 |
| --- | --- |
| 右上 | 滚动到顶端 |
| 右下 | 滚动到底端 |
| 上下 | 刷新 |
| 下右 | 关闭当前标签 |
| 下左 | 打开最近关闭的标签 |

默认配置可以在扩展弹窗中恢复。可选手势包括单方向和两段折线。

## 加载到 Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。

Chrome 的内部页面、Chrome 网上应用店页面和部分受保护页面不允许扩展注入脚本，因此这些页面无法绘制手势。
